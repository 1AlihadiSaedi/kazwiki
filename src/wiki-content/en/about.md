# About Emerald Wiki

Emerald Wiki is an **open-source**, fully **static** personal wiki.

## Goal

The main goal is to build a personal wiki that:

- Runs on **any static hosting** provider
- Has a tiny footprint (fits in 256 MB hosting)
- Requires no Node.js, PHP, or database
- Fully supports Persian (RTL) and English (LTR)

## Technology

Built with only three technologies:

- **Svelte** — Component framework
- **Pure CSS** — No external libraries
- **JavaScript** — No TypeScript

## Limitations

Since the site is fully **static**, there are some limitations:

1. **Real authentication** is not possible
2. **Server-side saving** is not possible — use the local editor
3. **Dynamic search** is limited — search only works across loaded pages

See the [Home page](#/home) for editing instructions.
